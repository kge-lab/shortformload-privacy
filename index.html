처리하는 정보

  • 사용자가 붙여넣거나 공유한 공개 Threads, Instagram, X 또는 YouTube 영상 링크를 처리합니다.
  • 처리 요청 때 링크, 기기 IP 주소, User-Agent를 포함한 일반 HTTPS 통신 정보가 해당 서비스 및 미디어 CDN에 직접 전달됩니다. 운영자 서버를 거치지 않으며, 수신자의 처리는 각 서비스 정책에 따릅니다.
  • 공개 게시물 HTML·미디어 정보와 미디어 파일은 미리보기와 사용자가 선택한 저장 기능에 사용됩니다. Threads·Instagram·X 요청에는 Googlebot User-Agent를 사용하며, YouTube 요청에는 추출 라이브러리가 지정하는 요청 헤더를 사용합니다.
  • 클립보드는 사용자가 붙여넣기 버튼을 누를 때 일반 텍스트만 읽습니다. URI·Intent의 내용을 읽어 오지 않습니다. 알림은 작업 상태와 취소 동작에만 사용합니다.

숏폼로드는 계정, 광고, 분석 SDK, 운영자 서버, 다운로드 이력 데이터베이스를 사용하지 않습니다. 연락처, 기기의 위치 센서, 카메라, 마이크, 설치된 앱 목록, 광고 ID에 접근하지 않습니다. 외부 수신자는 통신에 사용되는 IP 주소로 대략적인 위치를 추정할 수 있습니다.

보관과 삭제

  • 미리보기 파일과 ZIP은 앱 전용 임시 캐시에 저장됩니다. 다음 게시물 처리 또는 다음 작업 시작 때 앱이 만든 이전 임시 파일을 정리합니다. 강제 종료 직후 삭제는 보장하지 않습니다.
  • 저장 중 강제 종료로 남은 앱 소유의 미완료 공용 저장 항목은 앱 프로세스 재시작 후 첫 작업 때 정리합니다. 이미 저장 완료된 파일과 다른 앱의 파일은 이 정리 대상에 포함하지 않습니다.
  • 사용자가 저장한 사진·영상·ZIP은 기기 공용 저장소에 남습니다. 사용자가 갤러리 또는 파일 앱에서 삭제할 수 있으며, 앱을 삭제해도 남을 수 있습니다.
  • 운영자 서버에 링크, IP 주소, 미디어, 이용 기록을 보관하지 않습니다. 앱 전용 임시 파일은 앱 데이터 삭제로 제거할 수 있습니다.

앱 내부 데이터는 Android 클라우드 백업 및 기기 간 이전에서 제외하도록 설정합니다. 공용 저장 파일의 백업은 기기·갤러리 설정에 따릅니다.

제3자와 문의

앱은 HTTPS만 사용하며 사용자의 브라우저 쿠키, 로그인 세션, WebView를 사용하지 않습니다. YouTube 요청은 필수가 아닌 쿠키를 거절하는 고정 설정값을 전송할 수 있으며, 서비스가 반환하는 방문자 정보는 추출 중 메모리에서 처리합니다. 쿠키나 방문자 정보를 파일에 보관하지 않습니다. 해당 서비스의 공식 앱이 아닙니다. 공개 콘텐츠라도 저장 권한과 적용 법률, 플랫폼 약관은 사용자가 확인해야 합니다.
